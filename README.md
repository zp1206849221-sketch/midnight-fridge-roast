# Midnight Fridge Roast

A one-line roast of a smart fridge that refuses to open after midnight,
written for the make.fun "Midnight Fridge Roast" bounty. The fridge plays
nightclub bouncer at midnight — and the VIP section turns out to be leftover
lasagna and a drawer of dead lettuce.

## Run

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (creating the directory
if needed). Python 3 standard library only.
